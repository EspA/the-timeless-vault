Application Details (limit: 2000 characters)
----------------------------------------------
The Timeless Vault is an internal inventory and market-monitor for thetimelessvault.com, a LEGO collectibles retailer. Deployed on Google Cloud Run; staff-only access via Google SSO allowlist. Not a public marketplace and data is not resold.

FLOW
1. Staff create inventory records for LEGO sets (photos, condition, price).
2. Listings publish to Shopify, BrickLink, and eBay (Sell APIs — separate request).
3. Staff enable watch rules on sets they buy or sell.
4. Cloud Scheduler runs every 5 minutes; due watches call Browse API to fetch current eBay listings per set.
5. New listings and price-guard drift vs market median trigger internal email alerts.
6. Pricing changes are manual — no auto-bidding or repricing.

BROWSE API
• GET /buy/browse/v1/item_summary/search — one per watched set per scan (default 5 min). Query: LEGO {setNumber}, limit=200, New condition.
• GET item_summary/search — up to 3 catalog lookups per publish (GTIN/keyword).
• GET /buy/browse/v1/item/{itemId} — up to 6 detail lookups per publish for ePID/MPN/specifics.

Browse data is for internal monitoring only; not redistributed. eBay URLs appear in staff alert emails.

WHY HIGHER LIMIT
Each watch ≈288 search calls/day at 5-min interval. We are at/near the 5,000/day cap and hit errors 518/18000 when adding watches. Need headroom as inventory grows.

COMPLIANCE
OAuth 2.0 (client credentials for Browse, user token for Sell). Marketplace Account Deletion notifications subscribed. API License followed. URL: https://admin.thetimelessvault.com
